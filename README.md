## Currently building

<a href="https://github.com/Samudra-GITHub/Samagra-OS"><img src="./assets/profile/samagra-os.svg" width="100%" alt="Samagra OS: an animated terminal showing memory, interrupts and scheduler ok, and user mode early." /></a>

A real x86-64 operating system, built from first principles. It boots into long mode, manages physical and virtual memory, handles CPU exceptions and hardware interrupts, and runs a preemptive scheduler over kernel tasks. Early user-mode support has started: Ring 3, per-process address spaces and a small system-call interface. A filesystem, networking and a desktop are still to come.<br>
<sub>C · x86-64 assembly · Clang / LLD / NASM · QEMU &nbsp;·&nbsp; [GitHub ↗](https://github.com/Samudra-GITHub/Samagra-OS)</sub>

Claude Code and Antigravity are AI engineering agents, not people.
