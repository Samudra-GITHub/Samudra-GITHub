## Engineering with AI

<img src="./assets/profile/ai-workflow.svg" width="100%" alt="Engineering with AI: Samudra, a human engineer, directs two AI engineering agents. Claude Code works on UI, UX, design tokens and docs; Antigravity on boot, memory, interrupts, scheduler and drivers. Both share one repository with sync logs, handoff notes, docs, API contracts and commits, and a review, run, accept or reject loop returns to Samudra." />

Claude Code and Antigravity are AI engineering agents, not people. I use them as part of my workflow, not as a replacement for engineering decisions: I set architecture, direction and validation, and they implement. They coordinate through the repository itself: shared docs, interface contracts, handoff notes and commits.
