## 01 / CURRENTLY BUILDING

<a href="https://github.com/Samudra-GITHub/Samagra-OS"><img src="./assets/profile/samagra-boot.svg" width="100%" alt="A stylised Samagra OS boot sequence: memory, interrupts, timer and scheduler OK, keyboard input basic, kernel tasks running, no user space yet." /></a>

### SAMAGRA OS &nbsp;·&nbsp; समग्र OS

**A real x86-64 operating system, built from first principles.**

It boots into long mode, manages physical and virtual memory, handles CPU exceptions and hardware interrupts, and runs a preemptive round-robin scheduler over kernel tasks, all tested in QEMU. Keyboard input is basic. There is no user space, filesystem, networking or desktop yet, and the README says so.

<sub>C · X86-64 ASSEMBLY · CLANG / LLD / NASM · QEMU</sub>

It is developed through a human-directed AI engineering workflow, described in [03](#03--engineering-with-ai).

[**Samagra OS on GitHub →**](https://github.com/Samudra-GITHub/Samagra-OS)
