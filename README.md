## Currently building

<a href="https://github.com/Samudra-GITHub/Samagra-OS"><img src="./assets/profile/samagra-os.svg" width="100%" alt="Samagra OS: an illustrated kernel laboratory with an address-space map, privilege rings with system calls and a timer interrupt, and a round-robin scheduler. Boot, memory, interrupts and scheduler are implemented in QEMU; user mode and a RAM-only filesystem are early; kernel heap, networking, persistent storage, security hardening and a native desktop are planned." /></a>

A real x86-64 operating system, built from first principles. It boots into long mode, manages physical and virtual memory, handles CPU exceptions and hardware interrupts, and runs a preemptive scheduler over kernel tasks. Early user-mode support has started: Ring 3, per-process address spaces, a small system-call interface and a non-persistent RAM filesystem. Persistent storage, networking and a native desktop are still to come.<br>
<sub>C · x86-64 assembly · Clang / LLD / NASM · QEMU &nbsp;·&nbsp; [GitHub ↗](https://github.com/Samudra-GITHub/Samagra-OS)</sub>

## Engineering with AI

<img src="./assets/profile/ai-workflow.svg" width="100%" alt="Engineering with AI: Samudra, a human engineer, directs two AI engineering agents. Claude Code works on UI, UX, design tokens and docs; Antigravity on boot, memory, interrupts, scheduler and drivers. Both share one repository with sync logs, handoff notes, docs, API contracts and commits, and a review, run, accept or reject loop returns to Samudra." />

Claude Code and Antigravity are AI engineering agents, not people. I use them as part of my workflow, not as a replacement for engineering decisions: I set architecture, direction and validation, and they implement. They coordinate through the repository itself: shared docs, interface contracts, handoff notes and commits.
